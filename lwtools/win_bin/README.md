# lwtools for Windows

Put the Windows lwtools binaries here: `lwasm.exe` and `lwlink.exe`, with the DLLs they came
with (and, optionally, SRecord's `srec_cat.exe` for the BIOS's Intel-hex copy). The `.bat`
build scripts find them here through `lwtools_env.bat`. See the top-level `README.md`,
"Building from source". Nothing here but this file is part of the repository.
