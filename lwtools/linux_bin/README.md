# lwtools for Linux

Put the Linux lwtools binaries here: `lwasm` and `lwlink` (built from the lwtools source release,
`lwasm/lwasm` and `lwlink/lwlink` of the built tree), executable (`chmod +x` them if they came
here through Windows), and optionally SRecord's `srec_cat`. The `.sh` build scripts find them
here through `lwtools_env.sh`. See the top-level `README.md`, "Building from source". Nothing
here but this file is part of the repository.
